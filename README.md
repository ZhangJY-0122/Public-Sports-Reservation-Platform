# Public-Sports-Reservation-Platform

A Public Sports Reservation Platform based on Vue + Uni-app + Python, including a Uni-app mobile mini-program client, a Vue backend management end, and personal contact projects. It refers to the GroupPass mini-program. Users can realize functions such as reserving sports venues and participating in popular sports events.

#群众体育活动预约平台
基于 Vue+Uni-app+Python 的群众体育活动预约平台，包含 Un-iapp 客户手机小程序端，Vue 后台管理端，个人联系项目，参考群体通小程序，用户可实现预约体育场地，参加热门体育赛事等功能
