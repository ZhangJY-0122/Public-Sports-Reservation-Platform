📋 API接口概览

体育预约系统提供了完整的RESTful API接口，支持用户管理、场馆预约、活动赛事等核心功能

🔑 API基础信息

基地址：http://127.0.0.1:5000/api

数据格式：JSON

字符编码：UTF-8

📡 通用响应格式
所有API响应均采用以下统一格式
{
  "code": 0,
  "data": {},
  "message": "success"
}
字段 类型 说明
code integer 状态码，0表示成功，其他值表示错误
data object 响应数据
message string 响应消息
🛡️ 认证说明
需要认证的接口需要在请求头中携带用户ID
User-Id: <用户ID>
⚡ HTTP状态码
200
请求成功
400
请求参数错误
401
未授权，需要登录
403
禁止访问
404
资源不存在
409
资源冲突
500
服务器内部错误

🔐 用户认证模块

提供用户注册、登录、个人信息管理等认证相关接口

POST 用户注册
/api/auth/register

功能描述：创建新的用户账号

请求参数：

参数名 类型 必填 说明
username string required 用户名
email string required 邮箱地址
password string required 密码
phone string required 手机号
city string required 所在城市
real_name string optional 真实姓名

请求示例：

{
  "username": "zhangsan",
  "email": "zhangsan@example.com",
  "password": "123456",
  "phone": "13800138000",
  "city": "北京市",
  "real_name": "张三"
}
✅ 成功响应
{
  "code": 0,
  "data": {
    "user_id": 1,
    "username": "zhangsan"
  },
  "message": "注册成功"
}
POST 用户登录
/api/auth/login

功能描述：用户登录获取访问权限

请求参数：

参数名 类型 必填 说明
username string required 用户名或邮箱
password string required 密码

请求示例：

{
  "username": "zhangsan",
  "password": "123456"
}
✅ 成功响应
{
  "code": 0,
  "data": {
    "user_id": 1,
    "username": "zhangsan"
  },
  "message": "登录成功"
}

📖 使用说明

API调用示例和注意事项

🔑 认证示例

curl命令示例：

curl -X GET "http://127.0.0.1:5000/api/user/profile" \
  -H "User-Id: 1" \
  -H "Content-Type: application/json"

JavaScript fetch示例：

fetch('http://127.0.0.1:5000/api/user/profile', {
  method: 'GET',
  headers: {
    'User-Id': '1',
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => console.log(data));
💡 最佳实践

📌 注意事项：

  • 🔒 需要认证的接口必须在请求头中携带User-Id
  • 📊 所有接口都支持分页，使用page和page_size参数
  • 🔍 搜索接口支持关键词搜索和分类筛选
  • ⏰ 时间格式统一使用ISO 8601格式 (YYYY-MM-DD, HH:MM)
  • 💰 金额使用decimal类型，保留两位小数
  • 📱 错误响应包含详细的错误信息，请仔细检查
  • 🚦 遵守接口调用频率限制，避免请求过于频繁

🔄 状态管理：

  • 预约状态：pending(待确认) → confirmed(已确认) → completed(已完成)
  • 好友状态：pending(待处理) → accepted(已接受) → rejected(已拒绝)
  • 费用分摊：unpaid(未支付) → paid(已支付)
